# Altitude — Cloud & AI Journey

Altitude is a personal roadmap for learning cloud engineering and AI infrastructure. It turns a long list of courses, certifications, and project ideas into checkpoints I can actually work through, with tasks, deadlines, notes, and a clear view of my progress.

I made Altitude because I wanted one place to connect what I was studying with what I was building. The roadmap starts with AWS certifications and core skills such as Linux, networking, Python, and SQL. It then follows one evolving project through an API, containers, deployment on AWS, infrastructure as code, monitoring, and finally a Bedrock RAG feature. Each step adds something useful to the same larger story.

## What you can do

- Follow 24 starter checkpoints across seven learning phases, or add your own.
- Break checkpoints into tasks and mark them complete.
- Keep notes, resource links, start dates, and deadlines together.
- See upcoming work on the overview, browse deadlines in the calendar, and review progress in insights.
- Export a JSON backup of your progress or an `.ics` file for your calendar.

## Get Altitude

**[Download the React Native Android APK](Altitude-ReactNative-1.0.apk)**

The Android app is built with React Native and Expo. It keeps your roadmap on your phone and works offline; opening course links requires an internet connection.

Progress is stored locally on your device. There is no account or cloud sync, so keeping a backup is the best way to move it to another device.
